Domain-Driven Architecture

为叙事视频工业化定制的 9 大生产引擎

拒绝泛而不精的通用工具。从故事评估、四幕破题到演播提词，每一个功能都直接解决长视频创作者的生产瓶颈。

1. 下一步行动治理 (Next Action)

每个选题强制绑定当前唯一推进动作；支持稍后/跨天自动唤醒（UTC+8），自定义 3/5/7 天停滞警报标红，彻底斩断拖延。

抗拖延聚焦机制

2. 起承转合四幕叙事蓝图

黄金 3 秒 Hook、Why Now 驱动、核心 Pitch 提炼，内置【起·承·转·合】结构卡片与 Markdown 双向切换，一键注入正文草稿。

流水线一键注入

3. 5 维故事力评估罗盘

人物张力、戏剧冲突、荒诞反差、素材完整度、主线成立度；0~100 分综合力，智能定位内容短板并一键生成突破行动。

智能短板突破

4. 资料 3 级分层与直连解析

严格区分事实 (Fact)、线索 (Clue)、素材 (Material)；客户端原生 JSONP 直连 B 站 API 毫秒拉取互动数据，零风控拦截。

零服务端爬虫风控

5. 故事时间线与反差走廊

支持精确与模糊时序（年份/月份/待考证）混排，反差打标并在顶部生成水平连线的「情绪与叙事反差节奏走廊」。

反差节奏走廊

6. 人物档案与网状关系网

独立人物库管理别名、人设标签、经典语录与主页链接；自动渲染复杂人物双向/网状对立与合作图谱。

网状人物图谱

7. 演播气口与录音提词器

支持 `[停顿 1s]`、`[重音]`、`[反讽语气]` 等原子徽章；高对比度全屏提词器自动将气口转化为醒目导播灯，录音读错率直降。

原子演播气口徽章

8. 外部免密审稿与灵感快投

免登录只读审稿链接（到期物理自毁）；30s 心跳在线防踩踏锁；iOS 快捷指令/手机端 Webhook 一键直投碎片灵感。

自动销毁与快捷快投

9. 成片复盘与 5D 表现关联

直连 B 站 API 实时同步播放量、投币与弹幕；5D 评分与成片实际表现双柱关联图，科学提炼爆款因子。

成片数据闭环
实时交互诊断沙盒

Deployment & Infrastructure

单机容器与边缘云端双运行架构

开箱即用的生产级体验。本地一台轻量服务器即可单容器闭环，亦可零成本托管至 Cloudflare 边缘网络。

Docker / Podman 单容器一体化 (主力推荐)

内置 SQLite WAL + SPA 静态托管 + 反代自适应
零额外依赖

单镜像集成 Bun 原生 HTTP 核心与本地 SQLite WAL 数据库，自动自适应反向代理域名（Nginx / Caddy / CF Tunnel），分享链接即开即用。 

# 1. 快速克隆仓库
git clone https://github.com/biaobiaobiao108/TopicKanban.git
cd TopicKanban

# 2. 极速拉取并启动单容器 (映射 8787 端口与数据卷)
docker run -d \
  --name topic-kanban \
  -p 8787:8787 \
  -v kanban_data:/app/data \
  -e AUTH_PASSWORD=admin \
  topic-kanban:latest

# 3. 浏览器直接访问
http://localhost:8787

Cloudflare 边缘无服务器架构

Pages Functions + D1 SQLite + Workers KV
全球边缘秒开

代码通过 Hono 4 工厂统一驱动，原生兼容 Cloudflare D1 边缘数据库与 Workers KV，无需购买服务器即可享受毫秒级全球访问。 

# 1. 创建 D1 数据库与 KV 命名空间
npx wrangler d1 create topic-kanban-db
npx wrangler kv:namespace create TOPIC_KANBAN_KV

# 2. 一键发布至 Cloudflare Pages
bun run build
npx wrangler pages deploy dist
零维护成本 / 全球 CDN 加速 无服务器边缘
